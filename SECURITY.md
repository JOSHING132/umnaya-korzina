# Security

Не публикуйте в репозитории:

- `.env.local`;
- Supabase service-role key;
- пароли;
- токены доступа;
- приватные API-ключи;
- платёжные credentials.

Для публичного frontend-кода используйте только значения, которые действительно предназначены для публичного доступа.

Если вы обнаружили уязвимость, не публикуйте секреты или эксплуатационные данные в issue. Сначала свяжитесь с владельцами репозитория через предусмотренный ими приватный канал.
