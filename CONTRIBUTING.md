# Contributing

Спасибо за интерес к проекту.

## Перед отправкой изменений

1. Создайте отдельную ветку.
2. Не добавляйте `.env.local`, секреты, service-role keys или другие credentials.
3. Не добавляйте платёжные данные или приватные ключи в исходный код.
4. Проверьте приложение локально.
5. Перед pull request выполните:

```bash
npm run build
```

## Интеграции

Новые интеграции с магазинами, картами и другими сервисами должны быть отделены от основного интерфейса и не должны требовать публикации секретных ключей.
