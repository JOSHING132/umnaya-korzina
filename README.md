# 🛒 Умная корзина

> Open Source платформа для планирования питания, покупок и домашних запасов.

**Умная корзина** — проект, который объединяет меню, список покупок, домашние запасы и сравнение магазинов в одном приложении.

Идея проекта простая: пользователь планирует питание и покупки один раз, а приложение помогает понять **что нужно купить, где это можно купить и сколько будет стоить полная корзина**.

Проект развивается как открытая основа. Реальные каталоги торговых сетей, маршрутизация и другие внешние интеграции подключаются отдельно и не зашиты в публичную основу.

---

## ✨ Цель проекта

Создать удобное приложение, которое избавляет от необходимости вручную собирать список продуктов, открывать несколько приложений магазинов и самостоятельно пересчитывать покупки.

В перспективной версии пользователь сможет:

- составить меню на день или неделю;
- автоматически получить список необходимых ингредиентов;
- учесть продукты, которые уже есть дома;
- сформировать полноценную корзину;
- увидеть товары, которых нет в конкретном магазине;
- выбрать согласованные замены;
- сравнить полные корзины разных магазинов;
- учитывать время поездки до филиала;
- использовать общую корзину и запасы вместе с семьёй.

## 🔐 Безопасность и секреты

В публичный репозиторий нельзя отправлять:

- `.env.local`;
- пароли;
- API keys с приватными правами;
- Supabase `service_role` key;
- OAuth client secrets;
- токены внешних сервисов;
- credentials production-среды.

Для локальной разработки используется:

```bash
cp .env.example .env.local
```

Пример переменных:

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
```

`NEXT_PUBLIC_SUPABASE_ANON_KEY` предназначен для клиентского приложения. Приватные серверные ключи никогда не должны попадать во frontend.

Если секрет случайно попал в Git — его необходимо считать скомпрометированным и заменить у соответствующего провайдера.

Подробнее: `SECURITY.md`.

## 🚀 Быстрый старт

### Требования

- Node.js 18.17+
- npm
- аккаунт Supabase для функций, связанных с базой данных

### 1. Клонирование

```bash
git clone https://github.com/JOSHING132/umnaya-korzina.git
cd umnaya-korzina
```

### 2. Установка

```bash
npm install
```

### 3. Переменные окружения

```bash
cp .env.example .env.local
```

Заполните `.env.local`.

### 4. Supabase

Создайте проект Supabase и выполните:

```text
supabase/schema.sql
```

в SQL Editor.

### 5. Запуск

```bash
npm run dev
```

Откройте:

```text
http://localhost:3000
```

Геолокация работает на `localhost` либо в защищённом HTTPS-контексте.

## 📌 Принципы проекта

**Open Source first** — публичная основа должна оставаться пригодной для самостоятельного запуска и развития.

**Без обязательной оплаты** — базовая версия не зависит от платёжной системы.

**Провайдеры через адаптеры** — внешние сервисы не должны жёстко связывать бизнес-логику с одним поставщиком.

**Достоверность данных** — реальные цены и наличие нельзя выдавать за актуальные без подтверждённого источника.

**Privacy by design** — секреты и чувствительные данные не должны попадать в публичный клиент или Git.

**Mobile first** — основные действия должны оставаться удобными на телефоне.
